# UrbanEats - Food Delivery Landing Page

## Description

UrbanEats is a modern food delivery landing page developed using React.js and Vite. It provides users with an attractive interface to explore food items and place orders.

## Features

* Responsive Design
* Interactive UI
* Food Menu
* Shopping Cart
* Login Popup
* Mobile Friendly

## Tech Stack

* React.js
* JavaScript
* CSS3
* Vite

## Installation

npm install

npm run dev
